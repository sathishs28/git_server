For create project in Git server:
---------------------------------

Step-1: Login server as root user
 

Step-2: Go to GIT directory

		$ cd /home/git
	
	* Run below script file to create project repo 
	
		$ ./create_repo.sh

Note: Project name should have .git extention

	* After created your project, project url like below
	
		SSH url -> git@192.168.0.150:/home/git/your_project_name.git
		
		Http url -> http://192.168.0.150/git/your_project_name.git
		
	 Note: Replace your_project_name in url
	
	* You can refer project commit & history in web-browser
	
		Enter server ip in your browser - 192.168.0.150
	
----------------------------------
User/Member access for git server:
----------------------------------

Type1 - SSH Key access
----------------------

Step-1: Generate SSH key (id_rsa.pub) 

	* Open cmd/git-bash in User/Member PC, Use below cmd to generate the SSH key

		$ ssh-keygen -t rsa
	
		Note:After given above cmd there asking few input data (like file name, passpharse and etc), Don't give any input just press enter for all questions.

	* Refer the log, SSH keys are generated in Home directory (Inside have /.ssh/id_rsa.pub)

Step-2: Copy that SSH key inside of file "id_rsa.pub", and paste in Remote server (authorised_key)

	* Login Remote server as root user, 
	
	* Go to the directory - /home/git/.ssh/

	* add the user SSH key in the file "authorised_key"



Type2 - Http access
-------------------

Step-1: Login server as root user

Step-2: Use below cmd to create new user

		$ htpasswd /home/git/.htpasswd username
		
		Note: replace your username in username
	
	* View the added users, use below cmd
	
		$ cat /home/git/.htpasswd
	
	* To modify the existing user password repeate the same cmd

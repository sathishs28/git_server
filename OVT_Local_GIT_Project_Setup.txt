From local GIT Server Tag creating 
----------------------------------

1. For Last commit tag set
	
	# git tag -a Production_SW_V01 -m "Tagging version 1.1 at feature commit"
	
	# git push origin --tags
	
2. For set tag on sepecific commit

	# git tag -a Production_SW_V01 0bsdfsdree -m "Tagging version 1.1 at feature commit"
		Note: Replace commit ID & Message
		
	# git push origin --tags
	
	
3. Delete existing tag 

	# git tag -d <old_tag_name> 
	
		Note: To delete the tag from local repository
		
	# git push origin :refs/tags/<old_tag_name> 
	
		Note: To delete the exsiting tag from remote repo also
		
	# git push origin --tags
